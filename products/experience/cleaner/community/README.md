# 社区组件接入

首个候选是 Evolved 的播放器触摸手势，固定来源与逐文件 SHA256 见 [接入记录](evolved-player-gestures.json)。当前已准备接入边界，尚未安装手势监听，也没有导入完整 Evolved 运行时。

先在普通视频页接通横向拖动进度：移动时预览、松开时跳转、取消时不修改播放进度。使用上游 swiper 的轨迹识别与不同位置灵敏度映射；替换其设置读取、播放器查询、视频切换观察和 Vue2 提示界面。我们提供当前播放器适配、Vue3 提示和实例清理。后续设置归“播放器 - 优化 - 触摸操作”，初次接入默认关闭。

上游快照没有公开 Swiper 清理入口，touchcancel 和多点触摸也需要补上；这些是接入时直接处理的适配点，不先展开大规模模拟实验。只在真正接入后用完整脚本试一次拖动、取消、停用和视频切换，再交给用户在平板上试用。音量/画面亮度及预览缩略图随后加入，首步不调用缩略图 API。

源码入库时保留上游许可和出处，按自己的修改继续跟版；支持入口归 MisakaWeb。固定快照用于可复现接入，不代表已经追踪到上游最新版本。之后每次引入都登记固定来源、实际依赖、替换位置、启停清理和本地改动，功能组分类不能代替技术依赖。
