# 社区组件接入

首个实际接入原型是 Evolved 的播放器触摸手势，固定来源与逐文件 SHA256 见 [接入记录](evolved-player-gestures.json)。派生的手势数学和自有适配位于 [src/modules/touch](../src/modules/touch/README.md)，两个手势开关默认关闭，没有导入完整 Evolved 运行时。

普通视频页已接通横向拖动进度：移动时预览、松开时跳转、取消时不修改播放进度。使用上游 swiper 的方向识别与不同位置灵敏度映射；替换其设置读取、播放器查询、视频切换观察和 Vue2 提示界面。我们提供当前播放器适配、轻量原生 DOM 提示和实例清理，无需为这个预览再增加框架。设置归“播放器 - 优化 - 触摸操作”。

上游快照没有公开 Swiper 清理入口，我们补上了停用清理、touchcancel、多点触摸、控件避让以及阈值后的方向锁定。独立默认关闭的上下手势已接入画面亮度和音量，松开应用；亮度使用视频滤镜，音量能力取决于浏览器。首步不调用缩略图 API，不建模拟器；真实平板效果尚待用户验收。

源码入库时保留上游许可和出处，按自己的修改继续跟版；支持入口归 MisakaWeb。固定快照用于可复现接入，不代表已经追踪到上游最新版本。之后每次引入都登记固定来源、实际依赖、替换位置、启停清理和本地改动，功能组分类不能代替技术依赖。
