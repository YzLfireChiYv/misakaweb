# 配置管理与同步预留

registry.ts 从当前成品的全部页面规则和过滤模块汇总设置，按存储键去重，保留每个页面的默认值与约束。这是数据层注册入口，不是统一设置编辑器；日常设置仍由各页面栏目操作。备份界面仅调用导出/导入/恢复，导入后刷新应用。

所有产品GM读写与已使用的设备localStorage偏好通过 src/storage/configStorage.ts，原键不变。配置不是运行状态：缓存、迁移标记、规则同步时间戳、旧取舍和导入安全快照不进入可同步注册表。

JSON格式misakaweb-config-backup，schemaVersion1，含版本、成品、作用域、定义及saved/absent状态。settings/rules是用户配置候选；device只适合显式选择共享的设备偏好；secrets默认排除且不属于普通同步数据。缺省和显式值区分，导出不写入默认值。

导入先用本地注册表验证，导入文件的定义只作来源说明，不授予任意键写入权限。默认合并只写明确保存值；完整恢复也只清除文件明确absent的已注册项，不清空缺失作用域。未知/本成品不支持项跳过并提示。预览后值变动拒绝，失败尽力回滚；写入前保留一份本机完整快照（含连接信息），不自动导出或上传该快照。

导入关闭原自动规则同步开关，并优先写入该关闭值；本页批量写入也暂停旧同步至刷新。当前遗留WebDAV仍是规则时间戳包，未获得完整配置同步能力。未来同步模块应接注册表及统一读写入口，再单独实现操作记录、删除传播、并发合并、配额退避和版本迁移。不能把下载/上传这个JSON文件当作已完成同步协议。

当前本机位置来自当前bilibili子域的localStorage，未自动汇聚其它子域或其它设备；跨成品尚未支持能力未知项的同步保留。真实配置与凭据不得放入Git或公共维护诊断。桌面合成数据检查不等于全部管理器与WebDAV服务端验证。
